## 1. Pedagogical Architecture & Epistemology

Educational outcomes depend directly on the cognitive fidelity of learning materials. StudySourceCore rejects arbitrary summarization and unstructured flashcard dumping. Every study artifact generated by the system is structurally aligned with empirical cognitive science:

1. **Cognitive Load Theory (Sweller)**: Working memory is strictly limited ($\sim 4\pm 1$ elements). Instructional materials must eliminate *extraneous load* (unclear formatting, verbose conversational commentary, multi-part card questions) and optimize *germane load* (schema acquisition, problem categorization, deep structure mapping).
2. **Dual Coding Theory (Paivio & Mayer)**: Learning improves when verbal and non-verbal representations are integrated coherently. Spatial diagrams, anatomical charts, circuits, and mathematical notations complement text without redundant visual clutter.
3. **Desirable Difficulty & Active Retrieval (Bjork & Roediger)**: Durable retention requires effortful retrieval. Passive rereading yields an illusion of competence; atomic active recall, cloze deletions, and multi-stage problem-solving solidify neural retrieval pathways.

## 3. The 4-Stage Procedural Learning Progression

Procedural mastery in STEM and analytical disciplines (Mathematics, Physics numericals, Chemistry stoichiometry/mechanisms, Logical reasoning) cannot be achieved through rote memory flashcards. StudySourceCore enforces an explicit 4-stage instructional progression:

```text
┌──────────────────────────────────────────────────────────────────────────────────┐
│                     4-STAGE PROCEDURAL LEARNING PROGRESSION                      │
├───────────────────┬──────────────────────────────────┬───────────────────────────┤
│ Stage             │ Cognitive Function               │ Pedagogical Structure     │
├───────────────────┼──────────────────────────────────┼───────────────────────────┤
│ 1. Worked Example │ Schema Acquisition               │ Full expert demonstration │
│                   │ (Expert modeling, zero cognitive │ with stepwise rationale,  │
│                   │  overload on retrieval)          │ formulas, and annotations │
├───────────────────┼──────────────────────────────────┼───────────────────────────┤
│ 2. Faded          │ Guided Scaffolding               │ Backward fading: expert   │
│    Completion     │ (Transitional practice; partial  │ provides setup, student   │
│                   │  solution provided)              │ completes final steps     │
├───────────────────┼──────────────────────────────────┼───────────────────────────┤
│ 3. Independent    │ Autonomous Problem Solving       │ Full authentic question   │
│    Practice       │ (Full active retrieval under     │ with 3-tier hints and     │
│                   │  authentic exam constraints)     │ trap distractors (>= 4)   │
├───────────────────┼──────────────────────────────────┼───────────────────────────┤
│ 4. Transfer /     │ Boundary Generalization          │ Novel surface parameters, │
│    Far Practice   │ (Deep structure recognition      │ cross-topic variations,   │
│                   │  across varied contexts)         │ edge cases, compound items│
└───────────────────┴──────────────────────────────────┴───────────────────────────┘
```

### Stage 1: Worked Example
Provides an exhaustive, step-by-step demonstration of the governing algorithm. Every step explicitly documents:
- What operation was performed.
- Why that operation was chosen.
- What intermediate checks confirm progress.
- How units, constraints, and signs are tracked.

### Stage 2: Faded Completion
Employs backward-faded scaffolding (Renkl & Atkinson). The learner is provided with the complete initial setup (identifying given variables, drawing free-body diagrams, balancing stoichiometry) and must calculate or derive the final operational steps. This bridges passive comprehension and active execution.

### Stage 3: Independent Practice
Presents authentic previous-year questions (PYQs) or equivalent curated exam problems. The student must independently classify the problem family, identify recognition signals, select the governing method, and execute the derivation without initial assistance.

### Stage 4: Transfer / Far Practice
Challenges the learner with parameter variations, disguised problem formulations, and boundary conditions. This ensures that the student has internalized the *deep structure* of the problem rather than memorizing surface features.

## 4. `Pattern != Question`: Preserving Problem Instances

A core tenet of StudySourceCore is: **1 Pattern != 1 Question**.

- A **Problem Pattern** represents an underlying mathematical or logical schema (e.g., `family.math.lcm_hcf.coprime_factors` or `family.physics.kinematics.incline_friction`).
- A **Practice Question** is an authentic, concrete problem instance with specific parameters, context, and official exam provenance (e.g., RRB ALP 2018 Shift 2 Q14).

**Inviolable Rule**: Multiple authentic exam questions sharing the same problem family must **NEVER** be collapsed or deduplicated into a single generic template. Each distinct solvable question extracted from the authorized source must be preserved as an independent practice item with its own unique card anchor.

## 6. The 3-Tier Non-Leaking Hint Scaffolding Model

When learners encounter impasse during independent practice, immediate answer disclosure short-circuits learning. StudySourceCore enforces a 3-tier progressive hint ladder:

```
┌──────────────────────────────────────────────────────────────────────────────────┐
│                        3-TIER PROGRESSIVE HINT LADDER                            │
├────────┬──────────────────────┬──────────────────────────────────────────────────┤
│ Tier   │ Level Name           │ Pedagogical Content & Scope                      │
├────────┼──────────────────────┼──────────────────────────────────────────────────┤
│ Tier 1 │ Conceptual Approach  │ Identifies the governing principle or problem    │
│        │ (Schema Activation)  │ family without providing formulas or numbers.    │
│        │                      │ e.g., "इस प्रश्न में संवेग संरक्षण नियम लागू होगा" │
├────────┼──────────────────────┼──────────────────────────────────────────────────┤
│ Tier 2 │ Governing Method     │ Provides the relevant formula or algorithmic rule│
│        │ (Tool Identification)│ with variable definitions; does not plug in data.│
│        │                      │ e.g., "उपयुक्त सूत्र: m₁u₁ + m₂u₂ = (m₁ + m₂)v"   │
├────────┼──────────────────────┼──────────────────────────────────────────────────┤
│ Tier 3 │ Structural Setup     │ Demonstrates the algebraic or physical setup with│
│        │ (Near-Complete Scaffold) given values inserted, leaving arithmetic to do.│
│        │                      │ e.g., "(5 × 800) + (0) = (5 + 0.035) × v"        │
└────────┴──────────────────────┴──────────────────────────────────────────────────┘
```

### Inviolable Invariants for Hints:
1. **Terminal Answer Protection**: Under no circumstances may any hint tier (Tier 1, Tier 2, or Tier 3) reveal the final terminal numerical solution, final deduced state, or select the correct option key (e.g., "Option (B) is correct").
2. **Intermediate Scaffold Allowance**: Tier 3 is permitted to show the structural setup equation or execute an intermediate first-step calculation with values inserted when pedagogically justified, but the student must independently perform the terminal deduction and final calculation.
3. **Option Entropy Preservation**: Hints must not explicitly eliminate distractors (e.g., "Options A and C are incorrect") because this artificially reduces MCQ entropy from 4 options to 2.

## 7. Meaningful Parameter Variation & Cognitive Difficulty

When synthesizing practice variants (Stage 4 Transfer), parameter modifications must be mathematically, physically, and pedagogically valid:

- **Constraint Preservation**: If a problem requires coprime integers $a$ and $b$, variants must ensure $\gcd(a, b) = 1$. If a physics problem models friction, the coefficient of static friction $\mu_s$ must remain within physically plausible bounds ($0 < \mu_s \le 1.5$) and acceleration cannot exceed $c$ or produce negative kinetic energy.
- **Cognitive Difficulty Calibration**: Difficulty is not an arbitrary 1–5 score; it is a vector of three discrete dimensions:
  1. *Conceptual Complexity*: Number of distinct conceptual laws required (e.g., Conservation of Energy + Projectile Motion).
  2. *Computational Depth*: Number of arithmetic/algebraic operations required.
  3. *Trap Density*: Number of deceptive distractors or sign-convention pitfalls embedded in the question.

## 8. Semantic Deduplication vs. Lexical Matching

Deduplication must occur at the **semantic proposition layer**, not merely via string matching:

- Two flashcards with different wording but testing the exact same atomic proposition (e.g., "What is the unit of power?" vs "Watt is the SI unit of which physical quantity?") represent redundant review burden.
- The Semantic IR assigns stable Knowledge Unit (KU) IDs to propositions. If a KU is already exercised as a Basic flashcard, it is suppressed from generating a redundant Cloze card unless a specific pedagogical contrast is justified.

## 9. Interleaving: Sequencing vs. Authoring

Cognitive research demonstrates that interleaved practice (mixing problem types) produces vastly superior long-term discrimination compared to blocked practice (doing 50 LCM questions in a row).

However, StudySourceCore enforces an architectural separation:
1. **Authoring Time**: The authoring pipeline catalogs *recognition signals* and identifies *confusion pairs* (e.g., distinguishing Permutations from Combinations, or Series from Parallel circuits).
2. **Runtime Sequencing**: The dynamic interleaving of problem items belongs exclusively to the runtime practice scheduler (Anki custom study, StudyLab session runner). The compiler tags items with rich discriminator metadata, but does not hardcode mixed session order into static chapter decks.

## 10. Spacing & Review Burden Governance

StudySourceCore rejects arbitrary card volume and rigid study schedules:

### Rejection of Fixed Review Schedules
- **Fixed `1/3/7/21/60` day review intervals are strictly forbidden**.
- Arbitrary calendar schedules ignore learner forgetting curves, individual review latency, and topic difficulty.
- Spaced repetition scheduling is strictly runtime-managed (e.g., FSRS / Anki SM-2 algorithms) and must never be hardcoded into static artifact definitions or frontmatter notes.

### Sustainable Review Burden Philosophy (v1.0 Safety)
- High-yield curation takes precedence over raw generation.
- Operational safety limits (e.g., 15–35 high-yield flashcards per chapter) prevent review queue explosion. These bounds are treated as sensible cognitive safety envelopes rather than immutable scientific constants.

## 11. Bilingual Pedagogy: Hindi-First Standard

For students preparing for bilingual competitive examinations (e.g., RRB ALP, SSC, State PSCs), language barriers often obscure conceptual understanding. StudySourceCore enforces a strict bilingual standard:

1. **Explanatory Prose**: All narrative explanations, step-by-step derivations, hint instructions, and error analyses are authored in clear, natural Hindi.
2. **Technical Nomenclature**: Standard scientific and mathematical terms, laws, and symbols are stated in English within parentheses `( )` following the Hindi term:
   - Example: "गतिज ऊर्जा (Kinetic Energy)"
   - Example: "संवेग संरक्षण का नियम (Law of Conservation of Momentum)"
   - Example: "विभव प्रवणता (Potential Gradient)"
3. **Formulas and Equations**: Mathematical equations, chemical reactions, SI units, and algebraic symbols remain in standard international notation (e.g., $F = ma$, $\text{pH} = -\log[\text{H}^+]$, $\Omega$, $\text{m/s}^2$).
